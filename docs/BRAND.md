# 厚生錄 · 品牌系统

> 版本：v0.1 · 2026-10

本文档定义厚生錄的品牌资产：名字、标语、配色、字体、视觉隐喻、动效语言、文案语气。**所有页面与物料都应严格遵循本文档**，任何偏离需在 PR 中说明。

---

## 一、名字

### 中文名

**厚生錄**

### 英文名

**HouSheng Lu · Records of Living Well**

### 名字来源

"厚生" 出自《尚书·大禹谟》"正德、利用、厚生、惟和"，是中国古代"民生"主题的核心词。

### 名字选择理由

1. **语义对齐**：「厚生」= 重视民生 = 本书的核心
2. **不撞古籍**：与顾炎武《日知录》、贾思勰《齐民要术》、徐光启《天工开物》等经典书名均不重名
3. **音韵好**：hòu shēng lù，仄平平，朗朗上口
4. **跨语言**：中英文都好对应

### 不使用的名字

- "How to Live Better" —— 与三家现有衍生站（howtolivebetter.net 等）撞名
- "循证决策库 / 工具站 / Checklist" —— 落入工具类定位，与本书古籍气质不符
- 含 emoji 的名字（如 📚厚生录）—— 古籍气质不搭

## 二、标语

### 主标语

**七百条生计，都在案头。**

- **用途**：首页首屏、海报主标题、视频封面
- **含义**："案头"建立古籍书桌的画面；"生计"既指生活，也呼应经济
- **节奏**：八个字，可拆可合

### 副标语

**《高性价比人生指南》视觉化再刊本**

- **用途**：主标语下方一行小字、about 页首句
- **作用**：明确"再刊本"定位，做品牌切割；满足 CC BY 4.0 署名义务

### 短口号

| 口号 | 场景 |
|---|---|
| **花几分钟, 换回几年。** | 视频开头、公众号头图（引发点击） |
| **挑走一两条, 就算数。** | 海报副标题（直接借用作者原话） |
| **七百条, 不必全做。** | 海报、视频封面 |

## 三、视觉隐喻系统

这是本项目最核心的差异化资产。**所有 UI 元素都必须呼应古籍隐喻**。

### 主隐喻表

| 现代概念 | 古籍对应 | 实现方式 |
|---|---|---|
| 卡片 | 卷子 / 折页 | 不用圆角卡片，用折页效果（rotateY） |
| 高亮 | 朱印 | 选中/已做状态用朱砂印章动画 |
| 瀑布流 | 长卷 | 首页用横向长卷代替瀑布流 |
| 卡片分隔 | 朱丝栏 | 1px 朱砂红横线代替边框 |
| 红色按钮 | 急方 | 急救 PWA 用黑底朱砂字"急"字 |
| 链接 | 出处 | 不用按钮样式，用页面底部双行小字 |
| 通知小红点 | 印泥 | 用朱砂红小圆点 |
| ❤ 收藏 | 藏字 | 毛笔写"藏"字 SVG 描线 |
| ✓ 已做 | 钤印 | 朱砂印章盖下动画 |

### 不允许使用的视觉元素

- 渐变色（除极淡的纸纹背景）
- 拟物化阴影
- Material Design 风格的浮起按钮
- 大量 emoji
- 蓝紫渐变（典型 AI 风）

## 四、配色

### 主色板

```
背景:    #F2E8D5   竹纸黄
次背景:  #E8DCC0   旧书页
正文:    #2A2418   墨色
次文:    #6B5D4A   淡墨
强调红:  #8B3A3A   朱砂 (徽章/警示/链接 hover)
强调蓝:  #2C4A6B   靛蓝 (链接/引用)
印章红:  #B73229   印泥红 (选中/已做)
边框:    #C9B894   旧纸边
```

### 配色原则

1. **不鲜艳**：所有颜色都"旧"一档，像在宣纸上看
2. **不滥用红**：朱砂红只用于警示、徽章、印章、hover，不做大块底色
3. **不引入新色**：新组件只能从上面 8 色中选用，引入新色需更新本文档

### 暗色模式（急救 PWA 专用）

```
背景:    #1A1610   焦墨
次背景:  #2A2418   墨色
文字:    #F2E8D5   竹纸黄
警示:    #B73229   印泥红
```

## 六、动效语言

### 核心动效（克制度：每页不超过 1 处）

| 场景 | 动效 | 时长 |
|---|---|---|
| 卡片展开 | 仿线装书翻折（rotateY -90deg，transform-origin: left） | 280ms ease-out |
| 选中条目 | 朱砂印章盖下（圆形 scale + opacity） | 300ms |
| 收藏 | 毛笔写"藏"字 SVG 描线 | 600ms |
| 章节切换 | 整页向上推 + 新页升入 | 320ms ease-in-out |
| 急救按钮 | 朱砂印泥盖章效果（filter: blur + scale） | 200ms |

### 禁止的动效

- 整屏滚动视差
- 卡片 hover 大幅位移
- 渐变色流动
- 闪烁、抖动
- 加载旋转圈（用印章加载动画代替）

### 全局节奏

- 默认缓动：`cubic-bezier(0.4, 0, 0.2, 1)`
- 时长档位：120ms（小）/ 200ms（中）/ 320ms（大）

## 七、文案语气

### 语气总则

- 半文言半白话，**不口语化也不文言**
- 不出现 emoji
- 不用"我们 / 你"等强人称
- 用"卷 / 回 / 条 / 出处 / 急方 / 案头 / 卷末"等古籍词

### 提示语对照表

| 现代提示 | 古籍提示 |
|---|---|
| 加载中… | 卷开中… |
| 暂无数据 | 卷中尚无条目 |
| 点击查看 | 按此卷开 |
| 收藏 | 藏 |
| 已收藏 | 已藏 |
| 分享 | 传 |
| 返回 | 归卷 |
| 搜索 | 检索 |
| 急救 | 急方 |
| 设置 | 卷端 |
| 关于 | 卷末 |
| 错误 | 失卷 |
| 复制成功 | 已誊录 |

### 不使用的词

- 循证 / 决策库 / 工具 / 高效 / 一键 / 智能
- 用户画像 / 用户体验 / 转化率
- 截图 / 分享按钮（用"传"代替）
- App / 小程序（除非必要）
